# discord-bot-template

Plantilla profesional para bots privados de Discord usando **TypeScript** y **discord.js v14**.

Pensada para proyectos medianos/grandes, con buena arquitectura, hot-reload en desarrollo y build limpio para producción.

---

## ✨ Features

- TypeScript (strict)
- Discord.js v14
- Hot reload en desarrollo
- Build a JavaScript para producción
- Soporte temporal para archivos `.js`
- Path aliases (`@/`)
- MongoDB (mongoose)
- Logger personalizado

---

## 📦 Requisitos

- Node.js >= 18 (recomendado 20+)
- This project uses **pnpm** (recommended)
